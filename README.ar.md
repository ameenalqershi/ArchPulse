## الرؤية والمشكلة

يفصل المطور بين الحقيقة الموجودة في الشيفرة، والمعمارية التي قررها المهندس، ومسارات التشغيل التي أثبتتها التليمترية، والاستنتاجات التي قد يقدمها وكيل الذكاء الاصطناعي. يهدف ArchPulse إلى ربط هذه الأدلة بمخطط هندسي حي متدرج من النظام إلى الدالة، يستطيع الإنسان استخدامه للفهم والتوجيه والمراجعة دون خلط المقترح بالواقع.

المخطط المقصود ليس سطحًا واحدًا ضخمًا؛ بل خرائط متداخلة بحسب المجال والوحدة والخدمة والكلاس والدالة، مع مخططات Flow وDataJourney عند الطلب. وتعرض المخالفات المعمارية مع مصدرها وأثرها ولا تخفي التحذيرات عند طي التفاصيل.

## الوحدات المخطط لها

- **Engineering Knowledge Graph وRoslyn:** استخراج علاقات الشيفرة ومراجعها عبر الإصدارات.
- **ArchitectureGuardian:** التحقق من العقود المعمارية وشرح الانحراف بالدليل.
- **FeatureAtlas وDataJourney:** ربط وظائف الأعمال ومسارات البيانات مع ضمانات الخصوصية.
- **Live Observability:** ربط تشغيل النظام بإصدار BuildSHA، لا تخمين الواقع من التحليل الساكن.
- **OpenRepoLab وTest Execution Journey:** ربط الاختبار بالدالة على نفس الرسم وعرض الاستدعاءات والعوائد والاستثناءات والـAssertions وحالة الدليل وإعادة التشغيل.
- **Futures Engine / AET:** مقارنة البدائل الهندسية المعزولة وقياسها ثم إحالة القرار للإنسان.
- **Agent Gateway وCross-Agent Continuity:** تسليم العمل بين الوكلاء من Checkpoints وأدلة وعمليات استرداد آمنة.
- **Web Studio وVS Code وCLI وMCP Apps:** حوار ثنائي الاتجاه بين الرسم والمهندس والوكيل، مع Mermaid لكل بديل معماري.

كل ما سبق **مخطط للمنتج النهائي وغير منفذ** ما لم يرد دليل تنفيذ واختبار منشور.

## ما الموجود في حزمة التأسيس؟

ملفات رخصة وحوكمة ومساهمة وأمن ومخططات توثيق، وملف Solution مع مشروع صغير لعقود الدليل واختباراته. لا توجد مشاريع وهمية لتمثيل الوحدات غير المنفذة.

للبناء يتطلب .NET 10 SDK ثم:

```bash
dotnet restore ArchPulse.sln
dotnet build ArchPulse.sln --no-restore -c Release
dotnet test ArchPulse.sln --no-build -c Release
```

لم يُختبر البناء هنا لغياب SDK من البيئة المتاحة أثناء إعداد الحزمة؛ راجع تقرير التحقق. يمكن لأي مطور المساهمة عبر Fork وIssue وPull Request من غير اشتراط عضوية رسمية. يوضح [دليل المساهمة](CONTRIBUTING.md) و[الحوكمة](GOVERNANCE.md) طريقة ذلك.
