# Support channels

- **Questions and design discussion:** GitHub Discussions when enabled on the future public repository.
- **Reproducible bugs and missing docs:** GitHub issue templates.
- **Security issues:** private path in [SECURITY.md](SECURITY.md), never an ordinary public issue.
- **Foundation build assistance:** [First Contribution](docs/contributing/first-contribution.md) and [Developer Guide](docs/guides/developer-guide.md).

This is pre-release engineering; no production support, uptime SLA, or fixed response times. Community triage goal is 7 days if maintainers are available, not a guarantee.
