# Support and contributor communication

**Current state:** engineering foundation, not a released hosted product. No production SLA, paid support, or guaranteed maintainer response time is offered.

## Public channels

- [GitHub Discussions](https://github.com/ameenalqershi/ArchPulse/discussions): announcements, technical Q&A, architecture RFCs, contributor introductions and mentoring.
- [Welcome announcement](https://github.com/ameenalqershi/ArchPulse/discussions/16): starting point and community conventions.
- [GitHub Issues](https://github.com/ameenalqershi/ArchPulse/issues/new/choose): reproducible bugs, enhancement proposals, documentation, accessibility and performance reports.
- [Engineering roadmap Project](https://github.com/users/ameenalqershi/projects/1): work linked to specs and milestones.
- [First contribution tutorial](docs/contributing/first-contribution.md), [developer setup](docs/guides/developer-guide.md) and [contributing guide](CONTRIBUTING.md).

## Private security route

Use [private vulnerability reporting](https://github.com/ameenalqershi/ArchPulse/security/advisories/new) and read [SECURITY.md](SECURITY.md). Never create a public exploit disclosure ticket.

### Response targets

Volunteer maintainers aim to acknowledge a complete issue within 7 days and review a self-contained PR within 14 days **when available**; these are expectations, not guarantees. PR participation and issue comments do not require organization membership. Elevated member or maintainer privileges require explicit approved onboarding under [GOVERNANCE](GOVERNANCE.md).
