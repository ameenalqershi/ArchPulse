# Issue triage and response expectations

Labels: `bug`, `enhancement`, `documentation`, `architecture`, `security`, `performance`, `testing`, `help wanted`, `good first issue`, `blocked`, `ready`, `needs discussion`, `breaking change`. Use `area:*` and `priority:*` labels for scoped planning.

Initial response targets, **not guarantees**: acknowledge a well-formed issue within 7 days, review a self-contained PR within 14 days when volunteers are available. No obligation on volunteers.

For each task: confirm unique Txxx and Sxx, dependencies, acceptance criteria, tests, privacy constraints, code ownership, contributor suitability and actual CI state. Duplicate work is linked, not silently re-created. Security reports belong in the private vulnerability channel, not public Issues. Progress is updated in Notion only after evidence.
