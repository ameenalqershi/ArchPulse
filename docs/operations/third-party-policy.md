# Third-party licenses, provenance and NOTICE (Apache-2.0)

The root LICENSE is **Apache License Version 2.0** and must not be replaced without a separate, explicit owner decision. C# files should declare `SPDX-License-Identifier: Apache-2.0`. Do not invent a copyright holder: verified authors retain their own rights and attribution.

Before accepting third-party code/assets, record source, exact version, license, required NOTICE/attribution, modifications, redistribution obligations, security review and dependency approval. The offline [NuGet license metadata audit](NUGET-LICENSE-AUDIT.md) is an incremental foundation check, not full redistribution clearance; an explicit legacy-metadata exception remains pending review in issue #10. Check transitive packages including fonts and icons. If genuine third-party NOTICE obligations arise, add a root NOTICE preserving original notices. **No root NOTICE is generated here because no such attribution is yet identified; do not create placeholder notices.**

Apache-2.0 does not transfer trademarks or imply any third-party brand endorsement. An individual CLA is **not** imposed; consider a DCO only after public maintainer decision, without auto-signing on behalf of contributors. Review: S19.
