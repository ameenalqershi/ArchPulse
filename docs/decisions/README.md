# Architecture Decision Records (ADRs)

ArchPulse requires durable rationale for material design changes. An ADR is `Proposed` until human reviewers approve it; acceptance is not inferred from agent chat. Start with [ADR-template](ADR-template.md) and discuss in GitHub before cross-module changes. S22/S29/S32.

Initial candidate decisions (not accepted): local-first modular monolith, versioned evidence graph, storage/event ledger, explicit sandbox isolation, Mermaid-first review and human approval receipts.
