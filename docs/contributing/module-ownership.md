# Module ownership

Code ownership is based on demonstrated maintenance and explicit opt-in. Every module eventually needs a technical owner, a backup reviewer, stable contracts and test responsibilities. Current CODEOWNERS references the actual repository account owner only; it does not imply that other contributors accepted a role.

Nominate via Discussions/issue, review code quality and conduct, then grant least privilege after explicit approval. Read [GOVERNANCE](../../GOVERNANCE.md) and [MAINTAINERS](../../MAINTAINERS.md).
